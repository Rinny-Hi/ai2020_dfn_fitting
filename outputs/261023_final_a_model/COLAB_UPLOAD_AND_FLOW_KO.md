# Colab 실행 파일과 분석 흐름

## 1. 업로드할 파일

Colab에서 새 실행을 확인할 때 필요한 파일은 정확히 다섯 개다.

| 구분 | 파일 | 역할 |
| --- | --- | --- |
| 노트북 | `Ai2020_DFN_Chapter1_2_Colab.ipynb` | 입력 확인부터 DFN 실행, 오차 계산, 그래프 작성까지 수행한다. |
| 저율 데이터 | `260610 저율데이터 1.xlsx` | C/50 충·방전 반복곡선에서 기준 용량과 qOCV를 계산한다. |
| 저율 데이터 | `260610 저율데이터 2.xlsx` | 두 번째 C/50 반복 데이터로 기준 용량과 qOCV 평균을 구성한다. |
| 동적 데이터 | `260808 Eneterch셀 열화데이터 v1 6-6.xlsx` | 실제 0.5C·1C·2C 충·방전 전류, 초기 저율 방전, CV 종료전류와 비교 전압을 읽는다. |
| 전극 데이터 | `260902 Enertech셀 데이터 모음.xlsx` | `CATHODE_GITT` 시트의 7-7·7-8 반복시험으로 실측 양극 평균 OCP를 구성한다. |

먼저 Colab의 **파일 → 노트북 업로드**에서 노트북을 연다. 설치 셀 다음의 입력 셀을 실행하면 파일 선택 창이 열리며, 네 개의 Excel 파일을 한 번에 선택한다. 파일명은 코드에서 그대로 확인하므로 변경하지 않는다.

## 2. 실행 순서

1. Colab CPU 런타임에서 노트북을 연다.
2. 첫 설치 셀에서 `pybamm==26.8.0.0`과 `openpyxl`을 설치한다.
3. 네 개의 Excel 파일을 업로드한다.
4. 파일명, 필수 시트와 PyBaMM 버전 확인 결과가 모두 `✓`인지 확인한다.
5. 이후 셀을 위에서 아래로 순서대로 실행한다.
6. `DFN solve completed.`가 출력될 때까지 런타임을 중단하지 않는다.
7. 조건별 표, 통합 표, 전압 그래프와 음극 전위 그래프를 확인한다.
8. 마지막 셀에서 생성한 다음 CSV를 내려받아 실행 결과와 함께 보관한다.

   - `DFN_parameter_summary.csv`
   - `DFN_voltage_metrics_by_condition.csv`
   - `DFN_voltage_metrics_summary.csv`

설치 직후 버전 오류가 표시되면 런타임을 한 번 다시 시작한 뒤 설치 셀부터 순서대로 실행한다. GPU는 필요하지 않다.

| **1.4 기존 Ai2020 적용 모델의 한계** | 공개 parameter set만으로 남는 충전 전압 오차와 다변수 상호보상 위험을 설명한다. |

Chapter 1의 그래프는 다음 두 내용을 함께 보여준다.

- **qOCV reconstruction:** C/50 실험 qOCV와 Ai2020 양 전극 OCP 조합, 실측 양극 OCP 조합을 비교한다.
- **qOCV error:** 각 OCP 조합의 `모델 전압 − 실험 전압`을 mV로 표시한다. 표의 qOCV RMSE는 SoC 2–98% 구간에서 계산한다.

| **2.6 SoC별 음극 전위** | 충전 중 separator interface의 음극 표면 전위차를 모델 SoC에 따라 표시한다. |

연속 프로토콜은 다음 순서다.

```text
실제 저율 전류로 3.0 V까지 방전 → 10분 휴지
→ 0.5C CC–CV 충전 → 10분 휴지 → 0.5C 방전 → 10분 휴지
→ 1C CC–CV 충전 → 10분 휴지 → 1C 방전 → 10분 휴지
→ 2C CC–CV 충전 → 10분 휴지 → 2C 방전 → 10분 휴지
```

명목 C-rate와 별도로 workbook에서 읽은 실제 전류를 사용한다. 기준 용량으로 환산한 유효 C-rate는 약 0.484C, 0.968C, 1.935C다.

## 5. 전압 그래프와 오차 정의

전압 그래프는 2행 × 3열로 구성한다.

- 위 행: 0.5C·1C·2C 충전
- 아래 행: 0.5C·1C·2C 방전
- 검은 실선: 실험 전압
- 주황색 원형 marker: DFN 계산 전압
- 회색 음영: 각 실험 branch의 elapsed-time 10–90% 구간

오차는 같은 시간에서 `DFN 전압 − 실험 전압`으로 계산한다.

- **Time 10–90% RMSE/MAE:** 각 실험 branch의 전체 경과시간 중 10–90% 구간이다. SoC 10–90%가 아니다.
- **Common 0–99.5% RMSE/MAE:** 실험과 모델이 함께 존재하는 공통 시간구간의 0–99.5%다. 실험 전체 길이와 항상 같다는 뜻은 아니다.
- **통합 RMSE:** 여섯 조건별 RMSE를 동일 가중치로 두고 root-mean-square로 집계한다.
- **통합 MAE:** 여섯 조건별 MAE의 산술평균이다.

## 6. 새 실행 결과와 해석 범위

실제 전류, 초기 저율 방전과 각 충전의 실제 CV 종료전류를 읽어 연속 프로토콜을 새로 실행한 결과는 다음과 같다.

| 평가 구간 | 통합 RMSE | 통합 MAE |
| --- | ---: | ---: |
| Elapsed-time 10–90% | **19.796 mV** | **15.953 mV** |
| Common 0–99.5% | **42.507 mV** | **25.591 mV** |

“전압 오차 20 mV 이하”는 **elapsed-time 10–90% 구간에서 여섯 조건을 동일 가중치로 통합한 RMSE 19.796 mV**에만 적용한다. 전체 공통 시간구간의 RMSE는 42.507 mV이므로 전체 구간이 20 mV 이내라고 해석하지 않는다.

개별 조건도 모두 20 mV 이내는 아니다.

- 0.5C 충전 Time 10–90% RMSE: **23.390 mV**
- 1C 방전 Time 10–90% RMSE: **22.134 mV**

따라서 이 결과는 중앙 시간구간의 전체 평균적 정합도가 20 mV 수준임을 보여주지만, 모든 C-rate·방향 및 시작·종료 과도까지 같은 수준으로 재현했다는 의미는 아니다.

## 7. 결과 사용 시 제한

- 파라미터 선정과 전압 정합도 평가에 같은 실험 데이터가 포함된다. 독립 holdout validation이 아니다.
- 동적 검증은 한 셀의 연속 0.5C·1C·2C 이력에 기반한다. 다른 셀과 다른 온도로의 일반화는 별도 확인이 필요하다.
- 초기 상태는 실제 저율 방전과 10분 휴지를 모델에서 재현해 구성하지만, 시험 이전의 모든 내부 농도 이력이 직접 측정된 것은 아니다.
- 음극 전위는 `Negative electrode surface potential difference at separator interface`의 DFN 내부 예측값이다. 기준전극으로 직접 검증된 전위가 아니다.
- 음극 전위를 충전 제약조건으로 사용할 때는 mesh, 초기 상태, 파라미터 민감도와 안전 여유를 별도로 확인해야 한다.
- 최대 고체농도는 독립 측정값이 아니라 기준 용량, stoichiometry window, geometry와 활물질 분율을 일관되게 연결한 계산값이다.

다음 파일은 새 실행에 업로드하지 않아도 된다. 실행 결과를 대조하거나 보관할 때만 사용한다.

| 파일 | 용도 |
| --- | --- |
| `Ai2020_DFN_Chapter1_2_Colab.executed.ipynb` | 동일 입력으로 끝까지 실행한 결과가 포함된 참고 노트북이다. |
| `DFN_parameter_summary.csv` | 최종 적용 파라미터 요약이다. 새 실행의 마지막 셀에서 다시 생성된다. |
| `DFN_voltage_metrics_by_condition.csv` | C-rate·방향별 새 실행 전압 오차표다. |
| `DFN_voltage_metrics_summary.csv` | 충전·방전·전체 통합 오차표다. |

양극 GITT 원본 두 파일이나 별도의 DRT workbook도 이 노트북 실행에는 필요하지 않다. 양극 OCP는 통합 workbook의 `CATHODE_GITT` 시트에서 구성하며, 반응속도 coefficient는 최종 선정값을 고정해 사용한다.
