# 과거 10/20 공동 피팅과 현재 권고 조합: 방식·파라미터 차이

## 공통점

Cell 6-6 초기 RPT의 0.5C·1C·2C 정전류 곡선, Ai2020 흑연 음극 OCP, 측정 GITT 양극 OCP, ORegan2022 전해질 벌크 수송 물성, GITT `D_sn=4.1708×10⁻¹⁴`·`D_sp=6.8882×10⁻¹⁴ m²/s`를 사용했다. DFN은 등온, 전압 컷오프 충전 4.2 V/방전 3.0 V, 10초 출력, 각 방향 공간·입자 격자 15점 및 IDAKLU 허용오차 `rtol=10⁻⁶`, `atol=10⁻⁸`를 사용했다. 음극 전위는 둘 다 `Negative electrode surface potential difference at separator interface`이며 피팅 목적함수에는 넣지 않았다.

## 피팅 방식

| 항목 | 과거 10/20 공동 피팅 | 현재 권고 조합 |
| --- | --- | --- |
| 피팅 데이터 | 0.5/1/2C 충전 **및 방전**, 6곡선 | 0.5/1/2C **충전만**, 3곡선 |
| 별도 검증 | 같은 6곡선으로 사후 평가; 독립 방전 보류 없음 | 방전 3곡선을 피팅에서 제외하고 검증 |
| 조정 변수 | `k_n`, `b_n` 2개 | `b_n=2.5` 고정, `k_n` 1개 |
| 탐색 | PSO, 7입자×7반복, 시작 `b_n=2.914` | 범위 내 1차원 bounded scalar 탐색과 양 끝점 확인 |
| 범위 | `k_n=3×10⁻⁷–3×10⁻⁶`, `b_n=1.5–3.5` | `k_n=3×10⁻⁷–3×10⁻⁶`; `b_n` 고정 |
| 전압 비교점 | 곡선당 120점, 실험 종료시간 99.5%까지 | 곡선당 140점, 실험 종료시간 98%까지 |
| 조기 컷오프 처리 | 누락 시간점 잔차에 최대 500 mV 비율 페널티를 가산 | 방향·율당 20개 별도 항목에 300 mV×시간 부족률 |
| 용량·전위 | 피팅 후 진단만 | 피팅 후 진단만 |

두 최적값은 **서로 다른 데이터 분할과 목적함수**에서 나왔다. 과거의 방전 오차는 학습 성능이고, 현재의 방전 오차는 독립 검증이다. 현재 고정 `b_n=2.5`는 문헌 범위와 과거 피팅 `2.5336`에 가까운 값으로 선정했으므로 완전히 독립적인 모델 선택 검증은 아니다.

C/50 qOCV로 정한 음극 window는 과거 `x0=0.003806`, `x100=0.954221`, 현재 `0.003803`, `0.954167`로 사실상 같다. `c_s,max`도 따라서 거의 동일하다. 현재의 `k_p`는 EIS `R_ct,p=25.387 Ω cm²`, 각 OCP/window의 50% SoC 조성 및 현재 `c_s,max,p`로 환산했다. 현재 음극 EIS/DRT 초기값은 N3+N4 local-minimum 적분 `R_ct,n=27.0009 Ω cm²`에서 환산한 `k_n=6.3076×10⁻⁷`이지만, 최종 `k_n=9.7028×10⁻⁷`은 충전 전압 피팅값이다. 과거 피팅 시작 `k_n=9.6485×10⁻⁷`과 출처가 다르다.

## 음극 전위 차이의 통제 계산

현재 OCP/window와 시뮬레이터를 고정하고 과거 피팅의 `k_n,k_p,b_n,r_n,r_p`를 복원한 상태에서 **하나씩만 현재 값으로 변경**했다. 각 항목은 과거 기준에서 바꾼 경우의 차이로, 효과를 합산할 수는 없다.

| 변경 | 1C 최저 전위 변화 | 1C SoC 50% 변화 | 2C SoC 50% 변화 |
| --- | ---: | ---: | ---: |
| `k_n`만 +11.19% | +3.33 mV | +4.23 mV | +5.19 mV |
| `b_n`만 2.5336→2.5 | +2.02 mV | +1.51 mV | +2.83 mV |
| `r_n`만 3.7542→3.692 µm | +0.56 mV | +0.70 mV | +0.88 mV |
| `k_p`만 −19.18% | +2.01 mV | **+0.00 mV** | **+0.01 mV** |
| **모두 현재값** | **+7.87 mV** | **+6.40 mV** | **+8.90 mV** |

**해석:** 같은 SoC에서 음극 전위가 올라간 주요 요인은 `k_n` 증가와 `b_n` 감소다. `k_p` 감소는 같은 SoC의 음극 전위를 거의 바꾸지 않고 셀 전압 컷오프 시점을 앞당겨 **최저값이 관찰되는 종료 SoC를 바꾼다**. 그러므로 `k_p` 변경에 따른 최저 전위의 +2.01 mV를 순수 음극 전위 개선으로 읽으면 안 된다. OCP/window 및 `c_s,max` 차이는 0.01% 이하로 이 비교의 주원인이 아니다. 근거 원자료: `ORegan2022_과거현재_음극전위_파라미터기여.csv`.
