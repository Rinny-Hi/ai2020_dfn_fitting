| 기준 | 음극 window | cₛ,max,n (mol·m⁻³) | 50% SoC kₙ (A·m⁻²(m³·mol⁻¹)^1.5) |
|---|---|---:|---:|
| 첨부 A2 슬라이드: Ai2020 음극 + 측정 양극 OCP | x₀=0.003806, x₁₀₀=0.954221 | **25,182.8** | **6.3079 × 10⁻⁷** |

| 최신 비교 노트북의 *측정 음극 + 측정 양극 OCP* | x₀≈0.002150, x₁₀₀≈0.739784 | 32,447.1 | 5.0629 × 10⁻⁷ |

**A2/A4 슬라이드를 같은 Ai2020 음극 OCP 기준으로 연결한다면 25,182.8 mol·m⁻³를 사용한다.** 앞선 답변은 다른 측정 음극 OCP 조합의 32,447.1을 A2 슬라이드 값처럼 제시한 오류였다. 입자 반경 `rₙ=3.6920 µm`는 첨부 슬라이드 및 이후 제공된 노트북의 값이다.

슬라이드의 평균 용량은 `(2.355758+2.357298)/2 = 2.356528 Ah`이다. 그림의 계산식에 인쇄된 `2.35628 Ah`에는 숫자 **5**가 빠져 있다. 슬라이드의 `Qₙ=2.479472 Ah`와 `cₛ,max,n=25,182.8`은 `2.356528 Ah`를 넣으면 재현된다. 인쇄값 `2.35628 Ah`를 그대로 넣으면 `cₛ,max,n≈25,180.2`가 된다.

계산식: `Δx=0.954221−0.003806=0.950415`, `Qₙ=Q_cell/Δx`, `cₛ,max,n=3600 Qₙ/(F A Lₙ εₛ,n)`. 사용값은 `A=787.236 cm²`, `Lₙ=76.5 µm`, `εₛ,n=0.610`, `F=96485.33212 C mol⁻¹`이다.

## 2. 예전 N2/N3와 현재 N3/N4의 대응

예전 DRT 그림의 음극 피크 순서는 고주파에서 저주파로 대략 `~1 kHz (옛 N1) → ~20 Hz (옛 N2) → ~1 Hz (옛 N3) → ~0.1 Hz (옛 N4) → ~0.005 Hz (옛 N5)`였다. 이후 SoC별 DRT 그림은 `>10 kHz` 접촉 피크를 **현재 N1**로 분리해 `~1 kHz`를 **N2**, `~20 Hz`를 **N3**, `~1 Hz`를 **N4**로 표시한다. 따라서 **옛 N2/N3가 현재 N3/N4와 주파수상 대응한다.**

예전 면적표의 해당 합계는 `23.74489 + 6.95225 = 30.69714 Ω·cm²`이다. 예전 `N3+N4 = 6.95225 + 5.46027 = 12.41252 Ω·cm²`을 현재 N3/N4 저항으로 인용한 것은 번호 혼동이다. 다만 이 옛 peak-area 합계와 아래의 새 local-minimum 적분값은 **측정 데이터와 적분 방법이 다르므로 같은 수치로 취급하지 않는다.** 예전 발표자료의 Rct 계산 슬라이드도 표의 일부 피크 번호와 합산 문구가 서로 맞지 않는다.

이 대응은 `260818 현대자동차 미팅 자료`의 옛 peak-area 그림(7장)과 SoC별 피크 해석(5–6장)을 주파수 기준으로 대조한 결과다. 이 발표자료가 인용한 [2021년 논문](https://researchportal.hkust.edu.hk/en/publications/detection-of-lithium-plating-in-lithium-ion-batteries-by-distribu/)은 셀 구성별 DRT 피크 해석의 배경 자료다.

## 3. 현재 DRT 원본의 local-minimum 적분: 50% SoC

| 항목 | 값 |
|---|---:|
| N4/LF local minimum | 0.2861 Hz |
| N3/N4 local minimum | 5.0447 Hz |
| N2/N3 local minimum | 86.4315 Hz |
| 현재 N4 기여 | 9.9608 Ω·cm² |
| 현재 N3 기여 | 17.0401 Ω·cm² |
| **Rct = 현재 N3 + N4** | **27.0009 Ω·cm²** |
| **j₀** | **0.2509 A·m⁻²** |
| **kₙ, A2 슬라이드 window** | **6.3079 × 10⁻⁷ A·m⁻²(m³·mol⁻¹)^1.5** |

원본 `Ai2020_Anode_DRT_Frequency_Origin_Paste.xlsx`의 γ는 10 mm 전극 면적을 반영한 Ω·cm²이다. Savitzky–Golay 필터(21점, 3차)는 골 위치를 찾는 데만 쓰고, **원본 γ를 `d ln f`에 대해 사다리꼴 적분**했다. `Rct,A`는 식에 대입할 때 Ω·cm²에서 Ω·m²로 바꿨다. `T=298.15 K`, `cₑ=1000 mol·m⁻³`를 가정했다. 전체 10–90% SoC의 Rct는 `26.2040–27.7990 Ω·cm²`이다. 상세 결과는 동봉 CSV에 있다. [DRT 피크 저항을 인접한 골 사이에서 적분하는 방법](https://www.mdpi.com/2313-0105/7/3/52)을 사용했다.

N3/N4를 모두 음극 charge transfer로 배정한 `kₙ`은 DFN fitting **초기값**이다. harvested anode half-cell EIS의 Li counter/SEI 및 표면 상태 영향을 독립적으로 제거한 확정 물성치는 아니다.
