# 최종 fitting 지점의 Dsn 교차 비교

## 목적

ORegan2022 `b_n=2.914` 시작 fitting 결과인
`k_n=8.726541e-7`, `b_n=2.533583`을 고정하고 음극 고상 확산계수만 비교했다.

- GITT `Dsn`: `4.170774e-14 m²/s`
- Ai2020 `Dsn`: `3.9e-14 m²/s`

Cell 6-6 초기 RPT의 0.5C·1C·2C 충·방전 6곡선을 같은 초기화, cut-off 및
오차 정의로 계산했다. 재fitting은 수행하지 않았다.

## 결과

| 조건 | 전체 RMSE | 중앙 RMSE | 용량 RMSE | 최대 용량오차 |
| --- | ---: | ---: | ---: | ---: |
| GITT Dsn | 37.541 mV | 22.737 mV | 1.867% | 53.283 mAh |
| Ai2020 Dsn | 37.659 mV | 22.704 mV | 1.876% | 53.721 mAh |

| 조건 | 1C 충전 최저전위 | 2C 충전 최저전위 | 2C의 0 V 미만 시간비율 |
| --- | ---: | ---: | ---: |
| GITT Dsn | -11.210 mV | -59.723 mV | 52.797% |
| Ai2020 Dsn | -11.265 mV | -59.798 mV | 52.782% |

## 판단

- `Dsn` 차이는 약 6.9%지만 전체 전압 RMSE 차이는 0.12 mV, 용량 RMSE 차이는
  0.01%p 수준이다.
- 현재 0.5C–2C terminal-voltage 데이터만으로 두 `Dsn`을 구분하기 어렵다.
- 성능 차이가 없다는 이유로 문헌값으로 되돌리지 않는다. 대상 전극에서 얻은 물리적
  anchor라는 근거로 GITT `Dsn`을 고정한다.
- `Dsn`을 고정한 뒤 `k_n`과 `b_n` fitting 결과를 해석한다.

재현 스크립트: `compare_final_dsn_ai2020_gitt.py`
