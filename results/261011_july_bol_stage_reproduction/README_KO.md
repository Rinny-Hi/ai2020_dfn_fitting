# 2026-10-11 July BoL Ai2020 DFN 단계별 재현

## 상태와 범위

[`261011 Ai2020 July BoL DFN 단계별 재현.ipynb`](../../261011%20Ai2020%20July%20BoL%20DFN%20단계별%20재현.ipynb)는 Geometry → OCP → stoichiometry window → `Dsn/Dsp/kp`의 영향을 July BoL 셀 3개(`6-5`, `6-6`, `6-8`)에서 분리해 비교한 **단계별 진단**이다. 별도의 kinetics/transport 최종 피팅 결과가 아니다. 로컬 PyBaMM `26.8.0.0` 실행에서 10개 시나리오 × 3셀과 양극 hysteresis 진단이 실패 없이 완료됐다. 저장된 전압 표는 셀별 CC 오차를 C-rate·방향별로 평균한 값이다.

기존 [`260927_charge_physical_time_final`](../260927_charge_physical_time_final/README_KO.md)의 charge 피팅·discharge 검증 결론을 이 진단으로 대체하지 않는다. 모델, 초기화, 비교 구간이 다르므로 두 결과의 RMSE를 직접 개선량으로 빼지 않는다.

## 입력과 공통 조건

| 항목 | 적용값·출처 |
| --- | --- |
| qOCV | `260610 저율데이터 1.xlsx`, `260610 저율데이터 2.xlsx`의 완전 C/50 충·방전 각 8개 평균 |
| 양극 OCP | `260902 Enertech셀 데이터 모음.xlsx`의 기존 7-7/7-8 GITT 충·방전 휴지전압 평균 |
| 음극 OCP | PyBaMM Ai2020 graphite equilibrium |
| 동적 검증 | `260703 BoL 데이터 6-5.xlsx`, `6-6.xlsx`, `6-8.xlsx`의 실제 순차 CC/CV/휴지 이력 |
| Geometry | overlap 면적 787.236 cm²; 음/양극 두께 76.5/68 µm; SEM 반경 3.7542/4.2387 µm |
| window | `x0=0.003806`, `x100=0.954221`, `y0=0.970746`, `y100=0.431642` |
| 유효 `c_s,max` | 음/양극 25,182.8/49,140.1 mol m⁻³; 해당 window와 용량 보존으로 산정한 값이며 독립적인 소재 고유값 측정이 아님 |
| 전해질 확산 | 모든 단계에서 Ai2020 `D_e × 10⁻⁴`를 공통 적용 |

선정 OCP의 C/50 qOCV SoC 2–98% RMSE는 **6.243 mV**였다. 별도 기존 후보 비교에서는 실험 음극+기존 양극 8.220 mV, Ai2020 양 전극 16.354 mV였다. 이는 저율 셀 전압 적합도이며 개별 음극 전위의 실측 검증이 아니다. 새 9월 양극 GITT 후보는 역방향 coverage와 절대 stoichiometry anchor 부족으로 이번 기준 OCP에 섞지 않았다.

첫 기록 이전의 셀 내부 이력은 알 수 없어, 셀별 첫 휴지 종점전압을 해당 단계의 qOCV에 역산한 **균일 초기 상태**로 시작한다. 기록된 이후의 CC/CV/휴지는 순서대로 연결하고 CV 종료는 원본의 C/10으로 둔다. 따라서 이력 반영은 첫 기록 이후에 한정된다.

## 전압 결과

아래는 **각 모델과 실험이 함께 존재하는 CC 겹침 시간**의 평균 RMSE [mV]다. 충전·방전 순서로 적었다.

| 단계 | 0.5C | 1C | 2C |
| --- | ---: | ---: | ---: |
| S0: Ai2020 + 공통 `D_e` 보정 | 89.52 / 72.81 | 92.31 / 71.56 | 93.09 / 49.80 |
| S3: + Geometry, 양극 OCP, window | **46.51 / 42.90** | **54.83 / 49.33** | **59.41 / 47.78** |
| S8: S3 + GITT `Dsn/Dsp` + EIS 평균 `kp` | **41.44 / 35.92** | **49.92 / 40.87** | **53.58 / 28.55** |
| S9: S8 + 과거 July fitted `kn` 전이 | 47.31 / 45.30 | 56.61 / 53.26 | 59.63 / 36.97 |

S8에서 `Dsn=4.1708×10⁻¹⁴`, `Dsp=6.8882×10⁻¹⁴ m²/s`, `kp=5.6964×10⁻⁷`을 썼다. S9의 `kn=1.4502×10⁻⁶`은 다른 고정 조합에서 피팅한 값을 옮겨 본 진단이며 S8 조합에 다시 피팅한 결과가 아니다. S8이 모든 개별 조건의 최적 단계라는 뜻은 아니다.

조기 cutoff 이후는 위 RMSE에 포함되지 않는다. 예를 들어 S3의 **2C 충전 최소 시간 coverage는 90.1%**, S8은 **98.3%**다. 모든 시나리오가 존재하는 같은 시간창의 RMSE도 노트북에 있으며, 그 공통창은 2C 충전에서 실험 CC 시간의 **85.9%**만 덮는다. 따라서 이 수치로 전구간 또는 SoC 10–80% 목표 달성을 주장하지 않는다. 표시된 모든 조건은 20 mV를 넘는다.

양극 one-state hysteresis(`γ=3.2`, 초기 상태 0)는 S8 대비 일부 조건에서 RMSE를 0.25–2.52 mV 낮췄다. `γ`와 초기 상태가 측정·피팅된 값이 아니므로 채택된 물성으로 보지 않는다. 전극별 절대 전위도 독립 기준전극으로 검증되지 않았다.

## 8월 OCP 후보에 대한 추가 판단

사용자가 제공한 `260818_0단계~2단계_진행_결과_RctN2반영.ipynb`의 저장 출력은 실험 음극+실험 양극 OCP와 그 데이터에서 재식별한 window가 **8월 C/20 qOCV SoC 2–98% RMSE 10.99 mV**를 얻었다고 보여준다. Ai2020 양 전극 24.61 mV보다 낮으므로 *그 데이터의 저율 셀 전압*을 설명하는 유효 후보였다. 이는 6월 C/50 기준 6.243 mV와 데이터·geometry·window가 달라 직접 순위를 비교할 수 없다.

8월 코드는 음극/양극을 동시에 바꾼 두 조합만 비교해 전극별 개선을 분리하지 않았다. 반쪽전지 용량축을 음극 `x=0`, 양극 `y=1` endpoint에 고정하며, window의 `x0` 최적값이 탐색 하한 `0.0001`에 붙었다. 저장된 그림에서는 SoC 0% 모델 전압이 약 2.7 V로 실험 약 3.0 V와 다르다. 해당 노트북은 `xlsx_files`를 정의하지 않아 위에서부터 실행하면 실패하며 Stage 2 동적 결과도 저장돼 있지 않다. `Rct→j0→k` 산술은 지정된 입력값으로 재계산해 일치했지만 원본 OCP의 완전 재실행은 별도 검증이 필요하다. 따라서 실험 OCP를 폐기하지 않고 다음 비교의 후보로 유지하되, 음극 전위의 확정 기준으로 승격하지 않는다.
