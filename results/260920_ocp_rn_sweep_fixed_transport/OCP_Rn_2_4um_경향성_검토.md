# 여러 OCP 기반 Rn 2–4 µm 경향성 검토

## 적용 조건

- Dsn = 2.1e-14 m2/s
- Dsp = 4.4e-14 m2/s
- 전해질상 Bruggeman coefficient: b_n = b_p = b_s = 1.5
- 고체상 Bruggeman exponent: Ai2020 기본값 0 유지
- Rp = 3 µm 고정
- Rn = 2, 3, 4 µm
- 신규 260918 GITT는 제외
- qOCV/stoichiometry window는 이전 질량 비의존 OCP 검토 결과를 그대로 사용
- 0.5C, 1C, 2C charge/discharge는 fitting에 사용하지 않고 검증에만 사용

## 해석

1. 모든 OCP에서 Rn이 2→4 µm로 커질수록 charge와 discharge 전압 MAE 및 종료용량 오차가 단조 감소했다.
2. 이 조건에서는 Rn=4 µm가 가장 좋지만, 최소값이 탐색 상한에 있으므로 4 µm가 실제 최적값이라는 뜻은 아니다. Rn>4 µm 방향에 더 좋은 영역이 남아 있다는 신호다.
3. Rn 증가 시 Rn²/Dsn 확산 시간상수가 190.5→428.6→761.9 s로 증가하고, 반응 비표면적은 Rn=3 µm 대비 150%→100%→75%가 된다. 두 효과 모두 분극을 증가시키는 방향이다.
4. 실험 charge 전압은 모델보다 높고 discharge 전압은 모델보다 낮았다. 따라서 Rn 증가로 분극이 커질수록 양 방향 모두 실험 곡선 쪽으로 이동해 MAE가 감소했다.
5. 여러 OCP 중에서는 Ai2020 nominal equilibrium + 측정 hysteresis가 전 Rn에서 동적 전압 오차가 가장 낮았다. hysteresis가 없는 Ai2020 nominal은 좋지 않았다.
6. 그러나 최선 조합도 동적 MAE 88.28 mV로, 변경 전 hybrid의 27.09 mV보다 61.19 mV 악화됐다. 평균 절대 용량오차도 37.77→95.62 mAh, 최대 오차도 94.59→364.99 mAh로 커졌다.

## 판단

요청한 고정값 조합 안에서는 **Ai2020 nominal equilibrium + 측정 hysteresis, Rn=4 µm**가 최선이다. 다만 절대 적합도는 채택 가능한 수준이 아니다. Dsp 증가와 전해질 Bruggeman 감소가 양극/전해질 분극을 너무 줄인 상태에서 Rn 증가가 부족한 분극을 보상하는 형태로 보인다. 따라서 이 결과만으로 Rn=4 µm를 물리적 추정값으로 확정하면 안 된다.

다음 검토에서는 OCP와 Rn을 유지한 채 Dsp와 Bruggeman을 각각 한 번에 하나씩 원래 값으로 되돌리는 ablation을 수행해야 악화의 주원인을 구분할 수 있다. Rn 범위를 더 넓히더라도 teardown 입도 근거 없이 단순 fitting 값으로 채택하지 않는다.
