# S7 seven-parameter sensitivity and identifiability

Current S6 baseline, evaluated on the six Cell 6-6 time-voltage branches
(0.5C, 1C, and 2C charge/discharge). Each parameter is perturbed by the same
plus/minus 5% physical effect. For a Bruggeman exponent, the perturbation is
defined through the corresponding effective transport factor `epsilon**b`.

## Main result

| Rank | Parameter | Relative sensitivity |
|---:|---|---:|
| 1 | `brugg_n` | 1.000 |
| 2 | `kp` | 0.448 |
| 3 | `kn` | 0.434 |
| 4 | `brugg_p` | 0.352 |
| 5 | `brugg_s` | 0.136 |
| 6 | `Dsn` | 0.073 |
| 7 | `Dsp` | 0.028 |

`Dsn` and `Dsp` remain below the 0.10 sensitivity threshold and should retain
their GITT anchors. `kn` and `kp` are individually sensitive but their
normalized sensitivity cosine is 0.991, so terminal-voltage data do not
separate them reliably. The preferred two-parameter subset remains
`kn + brugg_n` (normalized condition number 2.29). An exploratory
three-parameter subset is `kn + brugg_n + brugg_p` (condition number 7.61),
but it is less identifiable.
