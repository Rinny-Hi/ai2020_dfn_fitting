# Rn/Rp 조합 검토

## 단위 확인

입력 표기의 2, 3, 4 µm는 PyBaMM에 각각 2e-6, 3e-6, 4e-6 m로 전달했다. 반경이 2, 3, 4 m로 들어간 것은 아니다.

## 고정 조건

- Dsn = 2.1e-14 m2/s
- Dsp = 4.4e-14 m2/s
- 전해질상 Bruggeman: b_n = b_p = b_s = 1.5
- 고체상 Bruggeman exponent: Ai2020 기본값 0
- Rn = 2, 3, 4 µm
- Rp = 2, 3, 4 µm
- 반경 3x3 screen에는 Ai2020 nominal equilibrium + 측정 hysteresis 사용
- 최선 반경 조합에서 다른 OCP 후보 재검증

## 해석과 판단

반경을 크게 하면 R²/D 확산 시간상수가 증가하고 반응 비표면적 3*eps_s/R이 감소하므로 양극과 음극의 분극이 모두 증가한다. 현재 고정한 Dsp와 Bruggeman 조건에서는 모델 분극이 실험보다 부족하여, Rn과 Rp를 크게 할수록 charge는 위로, discharge는 아래로 이동하며 실험에 가까워진다.

그러나 현재 최선 79.38 mV도 변경 전 hybrid의 27.09 mV보다 52.29 mV 크다. 평균 절대 용량오차는 37.77→85.87 mAh, 최대 오차는 94.59→323.28 mAh로 악화된다. 따라서 현재 반경 조합은 요청한 D/Bruggeman 조합 안에서 상대적으로 최선일 뿐, 기존 모델보다 좋은 최종 모델은 아니다.

두 반경이 모두 상한으로 가는 결과는 실제 입자가 반드시 더 크다는 증거보다, 다른 파라미터에서 사라진 분극을 입자반경이 보상하고 있다는 신호에 가깝다. 특히 Dsp=4.4e-14 m2/s는 Ai2020 값 5.387e-15보다 약 8.17배 크므로 양극 고체확산 분극이 크게 감소한다. teardown 입도 근거 없이 Rp 또는 Rn을 더 키워 fitting하는 것은 권장하지 않는다.
