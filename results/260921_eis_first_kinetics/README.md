# EIS 1차 반응속도 적용 결과

## 적용 방식

- 첨부 이미지의 값: `kn = 2.48e-7`, `kp = 3.12e-7`
- Ai2020/Dualfoil 기본 교환전류 식의 prefactor는 양·음극 모두 `m_ref = 1e-11 F = 9.6485e-7`이다.
- 따라서 현재 PyBaMM 함수에 `kn`은 기본값의 0.2570배, `kp`는 0.3234배로 적용했다.
- OCP, stoichiometry window, `Rn=5 um`, `Rp=3 um`, `Dsn=2.1e-14 m2/s`, `Dsp=4.4e-14 m2/s`, Bruggeman 계수와 전해질 확산계수는 기존 현재 구성과 동일하게 고정했다.

## 결과

| Case | 평균 MAE (mV) | 충전 평균 MAE (mV) | 방전 평균 MAE (mV) | 평균 절대 용량오차 (mAh) |
|---|---:|---:|---:|---:|
| Current baseline | 31.24 | 31.51 | 30.98 | 30.92 |
| EIS kn only | 31.94 | 32.21 | 31.67 | 106.40 |
| EIS kp only | 15.47 | 12.27 | 18.66 | 62.15 |
| EIS kn + kp | 71.24 | 70.75 | 71.72 | 179.89 |
| EIS kn N4-only | 21.05 | 20.76 | 21.33 | 32.56 |
| EIS kn N4-only + EIS kp | 22.17 | 19.32 | 25.03 | 79.69 |

## 판단

N3+N4의 `kn=2.48e-7`과 `kp=3.12e-7`을 동시에 전 SOC/전 C-rate의 상수 prefactor로 직접 적용하면 전압과 용량 종료점이 모두 악화된다. 반면 N4-only `kn=7.40e-7`만 적용하면 평균 MAE가 31.24 mV에서 21.05 mV로 줄고 평균 절대 용량오차는 30.92 mAh에서 32.56 mAh로 거의 유지된다. 현재 비교에서는 N4-only `kn`과 기존 Ai2020 `kp`의 조합이 가장 균형이 좋다. EIS `kp`까지 적용하면 평균 MAE는 비슷하지만 용량오차가 79.69 mAh로 증가한다.
