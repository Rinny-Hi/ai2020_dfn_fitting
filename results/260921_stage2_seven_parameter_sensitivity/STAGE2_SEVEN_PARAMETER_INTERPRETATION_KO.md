# 3개 Bruggeman 계수를 포함한 민감도·식별성 재분석

## 결론

민감도 분석의 후보군에는 `brugg_n`, `brugg_p`, `brugg_s`를 모두 넣는 것이 물리적으로 타당하다. 세 영역 모두에서 전해질 유효 확산계수와 유효 전도도가 공극률의 Bruggeman 보정을 받기 때문이다.

다만 **후보군에 모두 포함하는 것**과 **세 값을 동시에 독립 최적화하는 것**은 다르다. 현재 C-rate/HPPC 데이터에서는 특히 `brugg_p`와 `brugg_s`의 전압 응답이 거의 동일하여 두 값을 따로 식별하기 어렵다.

## 동일 기준 비교

지수 자체를 똑같이 ±5% 바꾸면 영역별 공극률이 달라 공정한 비교가 아니다. 이번 분석에서는 각 영역의 실제 유효수송항 `eps_i**brugg_i`가 동일하게 ±5% 변하도록 각 지수를 perturb했다.

| 파라미터 | C-rate 통합 RMS 변화 | HPPC RMS 변화 | C-rate 상대 민감도 |
|---|---:|---:|---:|
| `brugg_n` | 3.47 mV | 0.41 mV | 1.000 |
| `brugg_p` | 0.77 mV | 0.15 mV | 0.221 |
| `brugg_s` | 0.38 mV | 0.08 mV | 0.108 |

영향 크기는 `brugg_n > brugg_p > brugg_s` 순서다. `brugg_p`, `brugg_s`도 0이 아니므로 민감도 후보에서 빼는 것은 적절하지 않지만, 현재 데이터가 두 값을 독립적으로 결정할 만큼 다른 전압 형상을 제공하지 않는다.

## Bruggeman 계수 간 cosine correlation

| 데이터 | `n-p` | `n-s` | `p-s` |
|---|---:|---:|---:|
| C-rate 통합 | 0.911 | 0.918 | **0.994** |
| HPPC | 0.940 | 0.921 | **0.990** |

`brugg_p`와 `brugg_s`의 0.99 이상 상관은 사실상 같은 방향의 전압 변화를 만든다는 의미다. 세 값을 모두 자유변수로 두면 최적화 알고리즘은 양극과 분리막 저항 기여를 임의로 서로 교환할 수 있다.

## 전체 후보 선별 결과

- C-rate 통합 자동 선별: `brugg_n + kn + brugg_p`
- C-rate charge: `kn + brugg_n + Dsn`
- C-rate discharge: `brugg_n + kp`
- HPPC: `kn + brugg_n + Dsn + brugg_p`

`brugg_s`가 자동 선별에서 제외된 이유는 민감도가 완전히 없어서가 아니라, 더 민감한 `brugg_p`와 지나치게 높은 상관을 보이기 때문이다.

전체 7개 파라미터의 정규화 민감도 조건수는 C-rate 65.8, HPPC 101.1로 증가했다. 따라서 일곱 값을 모두 동시에 자유롭게 fitting하는 것은 권하지 않는다.

## 3단계 권고

1. 민감도 분석과 보고에는 `brugg_n`, `brugg_p`, `brugg_s` 세 값을 모두 포함한다.
2. 1차 최적화에서는 `brugg_s`를 분리막 nominal 값 1.5에 고정하고 `brugg_n`, `brugg_p`를 후보로 둔다.
3. `brugg_n`과 `brugg_p`도 상관이 0.91–0.94이므로 넓은 독립 bound를 주지 않고 문헌/teardown 기반 prior 또는 좁은 물리 bound를 사용한다.
4. 더 보수적인 대안은 세 기준값의 비율을 유지한 채 전극/분리막 유효수송에 공통 scale 하나만 적용하는 것이다.
5. 세 계수를 완전히 독립적으로 추정하려면 분리막 tortuosity/ionic resistance 측정, 전극별 공극률·tortuosity 측정 또는 서로 다른 분리막 두께 실험처럼 영역을 분리해 주는 추가 데이터가 필요하다.

따라서 현재 단계의 정확한 표현은 **“세 Bruggeman 계수를 모두 민감도 후보에 포함하되, 현재 C-rate와 HPPC만으로 세 값을 동시에 독립 fitting하지 않는다”**이다.
