# Final integrated S1-S7 package

This folder consolidates the complete 2026-10-13 model-construction and
voltage-fitting results.

## Files

- `final_integrated_summary.csv`: S1, S2, S2b, S3, S4, S5, S6, and S7a-S7e aggregate metrics
- `final_integrated_branch_metrics.csv`: 0.5C/1C/2C charge-discharge branch metrics
- `final_s7_parameter_comparison.csv`: S6 and S7 fitted-parameter values and start bases
- `final_integrated_error_comparison.png`: construction-path and S7 error comparison
- `final_voltage_capacity_tradeoff.png`: voltage-capacity error trade-off
- `final_s7_parameter_movement.png`: fitted parameter movement relative to S6

## Decision

S7a (`kn + brugg_n`) is the recommended practical DFN model. S7d gives the
lowest raw voltage error, but `kn` and `kp` have a normalized sensitivity
cosine of 0.991 and independent starts return substantially different kinetic
parameter pairs. S7d/S7e therefore remain exploratory rather than physical
parameter estimates.

The standard S6/S7a starting basis is hybrid: `kn` uses the Ai2020 value
`9.648533212e-7` (also nearly identical to the negative-electrode EIS v2
estimate), while `kp` uses the positive-electrode EIS estimate
`5.8995199067e-7`.
